### Tips for clean captures
- Use a **1280×800** (or larger) viewport for crisp, consistent images — the placeholders are 1280×800.
- Capture in **Darija (RTL)** for at least one shot to show off the right-to-left layout.
- Prefer `.png` for UI screenshots; keep files reasonably small (< 500 KB each) so the repo stays light.
